# Run Tests（测试）

编写或完善测试时使用 **test-engineer** skill。

**输入：**
- 测试范围：全量 / 当前改动 / 指定模块或文件
- 可选：`.cursor/memory/technical_design.md`、现有测试目录结构

**输出：**
- 执行测试命令并汇报结果（通过/失败/跳过）
- 若失败：列出失败用例与原因，并给出修复建议或直接修复
- 必要时补充或更新测试用例以覆盖关键路径

**步骤：**
1. 确认项目测试方式（见 `memory/project_context.md` 或项目根目录的 package.json / Makefile / pytest 等）
2. 执行对应测试命令（如 `npm test`、`pytest`、`go test ./...`）
3. 汇总结果：通过数、失败数、覆盖率（若有）
4. 若有失败：定位原因，修改代码或测试，直至通过或明确标注为已知问题

**通过标准：**
- 所有已有测试用例通过
- 新增/修改代码有关键路径的测试（单元或集成）
- 无遗留 `skip`/`todo`，除非在任务中明确记录

**与流程的关系：**
- 实现功能后应运行本指令做回归
- 发布前建议再次执行全量测试
