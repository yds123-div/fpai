# 产品查询 Skill（数据获取）

## 目标

为“产品查询/榜单/筛选/推荐”类问题提供结构化数据输入，供上层大模型生成最终自然语言回答。

## 输入

- `question`: 用户问题（可能包含基金代码或榜单诉求）
- `ctx`: 上下文（目前仅透传，不强依赖）

## 输出（JSON 字符串）

- `mode = "symbols"`：识别到 6 位基金代码时，复用 `product_compare` 的聚合数据结构输出
- `mode = "rank"`：未识别到基金代码时，输出 TopN 榜单（默认 5），并补充稳健性参考信息（盈亏概率/胜率）

## 说明

- “低风险/稳健”当前通过“盈亏概率（胜率）”做近似，不等同于最大回撤/波动率等严格风险指标；后续如需严谨风险度量，可继续扩展接口来源或补充工具函数。
