# 理财分析 - Fund Analysis
## 快速开始
安装依赖：
pip install akshare pandas
## 支持的功能
### 1. 查询产品信息
根据产品名称或代码查询基金基本信息：
import akshare as ak
# 基金基本信息
fund_name = "招商中证白酒指数"
fund_zh_a_em(fund=fund_name)
# 基金净值
fund_nav_em(fund="161039", symbol="最新净值")
fund_nav_em(fund="161039", symbol="历史净值")
### 2. 对比产品
多只基金关键指标对比：
import akshare as ak
# 基金业绩走势对比
fund_zh_a_hist_compare(symbol=["161039", "110011"], period="近6月")
# 基金持仓对比
fund_stock_pool_compare(symbol=["161039", "110011"])
### 3. 产品解析 - 六大分析维度
#### 3.1 基本信息
基金基本信息、规模
#### 3.2 业绩表现
基金历史业绩
#### 3.3 行业风格
基金行业配置、重仓股
#### 3.4 资产配置
基金资产配置
#### 3.5 风险提示
基金风险指标
#### 3.6 结论
根据以上分析，生成综合结论
