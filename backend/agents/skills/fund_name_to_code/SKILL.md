# 基金名称转代码 Skill

## 目标

根据用户输入的基金名称，查询并返回对应的基金代码。当用户没有提供基金代码但提供了基金名称时使用。

## 输入

- `question`: 用户问题（可能包含基金名称，如"易方达蓝筹精选"、"招商中证白酒指数"等）
- `ctx`: 上下文（包含 session_id 等）

## 输出（JSON 字符串）

```json
{
  "ok": true,
  "matches": [
    {"code": "005876", "name": "易方达蓝筹精选混合", "type": "混合型"},
    {"code": "161039", "name": "易方达蓝筹精选混合C", "type": "混合型"}
  ]
}
```

## 说明

- 使用 AkShare 的 fund_basic_info_em 接口获取基金列表
- 支持模糊匹配（包含输入关键词即匹配）
- 返回匹配结果列表，由上层决定使用哪个
- 若无匹配返回空列表
