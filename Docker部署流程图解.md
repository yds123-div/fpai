## 🔄 构建流程详解

### 第一步：后端镜像构建

```
backend/Dockerfile
       │
       ▼
┌──────────────────────────────────────────┐
│ 1. 选择基础镜像                           │
│    FROM python:3.11-slim-bookworm        │
│    ↓                                      │
│    [Python 3.11 环境]                    │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 2. 设置工作目录                           │
│    WORKDIR /app/backend                  │
│    ↓                                      │
│    [创建 /app/backend 目录]              │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 3. 安装系统依赖                           │
│    RUN apt-get install gcc curl ...      │
│    ↓                                      │
│    [编译工具 + curl]                     │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 4. 安装 Python 依赖                       │
│    COPY requirements.txt                 │
│    RUN pip install -r requirements.txt   │
│    ↓                                      │
│    [FastAPI + 其他依赖]                  │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 5. 复制后端代码                           │
│    COPY . .                              │
│    ↓                                      │
│    [api/ + agents/ + 所有代码]           │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 6. 设置启动命令                           │
│    CMD uvicorn api.main:app              │
│    ↓                                      │
│    [准备就绪]                            │
└──────────────────────────────────────────┘
       │
       ▼
   后端镜像 ✅
```

### 第二步：前端镜像构建（多阶段）

```
frontend/Dockerfile
       │
       ▼
┌──────────────────────────────────────────┐
│ 阶段 1：构建阶段 (build)                  │
│ FROM node:20-alpine AS build             │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 1. 安装依赖                               │
│    COPY package*.json                    │
│    RUN npm install                       │
│    ↓                                      │
│    [node_modules/]                       │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 2. 构建前端                               │
│    COPY . .                              │
│    RUN npm run build                     │
│    ↓                                      │
│    [dist/ 目录]                          │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 阶段 2：运行阶段                          │
│ FROM nginx:1.27-alpine                   │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 3. 复制构建产物                           │
│    COPY --from=build dist/ /usr/share/  │
│    ↓                                      │
│    [只有静态文件，没有源码]              │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 4. 配置 Nginx                            │
│    COPY nginx.conf                       │
│    ↓                                      │
│    [反向代理配置]                        │
└──────────────────────────────────────────┘
       │
       ▼
   前端镜像 ✅
   (体积只有 ~50MB！)
```

## 🚀 启动流程详解

### docker-compose up -d 做了什么？

```
docker-compose up -d
       │
       ▼
┌──────────────────────────────────────────┐
│ 1. 读取 docker-compose.yml               │
│    - 发现 backend 服务                    │
│    - 发现 frontend 服务                   │
│    - 发现 fpai-net 网络                   │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 2. 创建网络                               │
│    docker network create fpai-net        │
│    ↓                                      │
│    [虚拟网络创建成功]                    │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 3. 启动后端容器                           │
│    docker run -d \                       │
│      --name fpai-backend-1 \             │
│      --network fpai-net \                │
│      --env-file backend/.env \           │
│      backend-image                       │
│    ↓                                      │
│    [后端容器运行中，监听 8000]           │
└──────────────────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│ 4. 启动前端容器                           │
│    docker run -d \                       │
│      --name fpai-frontend-1 \            │
│      --network fpai-net \                │
│      -p 3000:80 \                        │
│      frontend-image                      │
│    ↓                                      │
│    [前端容器运行中，80→3000]             │
└──────────────────────────────────────────┘
       │
       ▼
   部署完成 ✅
```

## 🌐 网络通信流程

### 用户访问前端

```
浏览器
  │
  │ 访问 http://localhost:3000
  │
  ▼
宿主机端口 3000
  │
  │ 端口映射
  │
  ▼
前端容器端口 80
  │
  │ Nginx 处理请求
  │
  ▼
返回 index.html
```

### 前端调用后端 API

```
浏览器
  │
  │ 发起请求：/api/v1/chat
  │
  ▼
前端容器 (Nginx)
  │
  │ nginx.conf 配置：
  │ location /api/ {
  │   proxy_pass http://backend:8000;
  │ }
  │
  ▼
后端容器 (FastAPI)
  │
  │ 处理请求
  │
  ▼
返回 JSON 数据
  │
  ▼
前端容器 (Nginx)
  │
  ▼
浏览器
```

### 后端访问外部服务

```
后端容器
  │
  │ 需要访问 MySQL
  │
  ▼
Docker 网络
  │
  │ 通过 host.docker.internal
  │ 或直接访问远程 IP
  │
  ▼
外部服务
  │
  ├─ MySQL (106.55.151.240:4407)
  ├─ Redis (host.docker.internal:6379)
  └─ 外部知识库 (139.9.59.175:8080)
```

## 📦 镜像分层结构

### 后端镜像分层

```
┌─────────────────────────────────────┐
│ Layer 7: 启动命令                    │  ← 最上层（最新）
│ CMD uvicorn api.main:app            │
├─────────────────────────────────────┤
│ Layer 6: 后端代码                    │
│ COPY . .                            │
├─────────────────────────────────────┤
│ Layer 5: Python 依赖                 │
│ pip install -r requirements.txt     │
├─────────────────────────────────────┤
│ Layer 4: requirements.txt           │
│ COPY requirements.txt               │
├─────────────────────────────────────┤
│ Layer 3: 系统依赖                    │
│ apt-get install gcc curl ...        │
├─────────────────────────────────────┤
│ Layer 2: 环境变量                    │
│ ENV PYTHONUNBUFFERED=1              │
├─────────────────────────────────────┤
│ Layer 1: 基础镜像                    │
│ FROM python:3.11-slim-bookworm      │
└─────────────────────────────────────┘
         ↑ 最底层（最旧）
```

**为什么分层？**
- 每层都可以缓存
- 修改代码只需重建 Layer 6
- Layer 1-5 可以复用，加快构建速度

## 💡 关键概念对比

### 镜像 vs 容器

```
镜像 (Image)                容器 (Container)
    │                           │
    │ 就像"菜谱"                │ 就像"做好的菜"
    │                           │
    ├─ 只读的                   ├─ 可读写的
    ├─ 可以复用                 ├─ 独立运行
    ├─ 存储在磁盘               ├─ 运行在内存
    └─ 可以创建多个容器         └─ 基于一个镜像
```

### 单阶段 vs 多阶段构建

```
单阶段构建                   多阶段构建
    │                           │
    ├─ 一个 FROM                ├─ 多个 FROM
    ├─ 包含所有内容             ├─ 只保留必要内容
    ├─ 镜像体积大               ├─ 镜像体积小
    └─ 构建简单                 └─ 构建复杂但高效

示例：
单阶段：1.5GB               多阶段：50MB
(Node.js + 源码 + dist)     (只有 Nginx + dist)
```

## 🎯 总结

### Docker 部署的核心流程

```
1. 编写 Dockerfile
   ↓
2. 编写 docker-compose.yml
   ↓
3. 配置环境变量 (.env)
   ↓
4. 构建镜像 (docker-compose build)
   ↓
5. 启动容器 (docker-compose up -d)
   ↓
6. 访问应用 (localhost:3000)
```

### 关键命令速查

```bash
# 构建镜像
docker-compose build

# 启动容器（后台运行）
docker-compose up -d

# 查看运行状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 停止容器
docker-compose stop

# 停止并删除容器
docker-compose down

# 重新构建并启动
docker-compose up -d --build
```
