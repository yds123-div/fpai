# 生成产品需求文档（PRD）

## 目标

根据业务需求生成完整的产品需求文档（PRD）

## 输入

- 业务需求描述
- 用户痛点
- 业务目标

## 输出

完整的 PRD 文档，包含：
- 产品概述
- 目标用户
- 用户故事
- 功能需求（按优先级）
- 非功能需求
- 用户流程
- 成功指标

## 执行步骤

### 1. 需求理解
- 阅读并理解业务需求
- 识别核心价值主张
- 明确目标用户

### 2. 需求分析
- 分析用户痛点
- 定义解决方案
- 识别关键功能

### 3. 编写 PRD
- 使用 #product-manager.md 角色
- 按照 PRD 模板编写
- 包含所有必要章节

### 4. 验证完整性
- 检查是否覆盖所有需求
- 验证用户故事的完整性
- 确认成功指标可量化

## 使用方式

```
使用 spec: generate-prd

业务需求：
[描述你的业务需求]
```

## 相关文件

- 角色：#product-manager.md
- 输出位置：项目文档目录
