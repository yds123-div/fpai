# 实现功能

## 目标

按照需求和设计文档实现功能，包括代码、测试和文档

## 输入

- 功能描述或任务
- 技术设计文档
- 编码规范

## 输出

- 可运行的代码
- 单元测试和集成测试
- 必要的文档和注释

## 执行步骤

### 1. 理解需求
- 阅读 PRD 和技术设计文档
- 明确功能范围和验收标准
- 识别依赖和约束

### 2. 设计实现
- 确定模块结构
- 设计接口和数据模型
- 考虑错误处理和边界情况

### 3. 编写代码
- 根据功能类型选择角色：
  - 后端功能：使用 #backend-engineer.md
  - 前端功能：使用 #frontend-engineer.md
- 遵循编码规范
- 添加必要的注释

### 4. 编写测试
- 使用 #test-engineer.md 角色
- 编写单元测试
- 编写集成测试（如需要）
- 确保测试覆盖关键路径

### 5. 验证实现
- 运行所有测试
- 手动测试关键功能
- 检查代码规范

## 使用方式

```
使用 spec: implement-feature

功能描述：
[描述要实现的功能]

类型：后端 / 前端
```
