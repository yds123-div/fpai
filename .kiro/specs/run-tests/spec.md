# 运行测试

## 目标

执行测试并分析结果，确保代码质量

## 输入

- 测试范围（全量 / 当前改动 / 指定模块）
- 项目测试配置

## 输出

- 测试执行结果
- 失败用例分析（如有）
- 修复建议或修复代码

## 执行步骤

### 1. 确认测试方式
- 检查项目测试配置
- 确认测试命令
- 了解测试框架

### 2. 执行测试
- 运行测试命令
- 收集测试结果
- 记录执行时间

### 3. 分析结果
- 统计通过/失败/跳过数量
- 分析失败原因
- 识别测试覆盖率（如有）

### 4. 处理失败
- 定位失败原因
- 修复代码或测试
- 重新运行测试

### 5. 补充测试
- 使用 #test-engineer.md 角色
- 识别测试覆盖盲点
- 补充缺失的测试用例

### 6. 输出报告
- 汇总测试结果
- 列出修复的问题
- 给出测试通过确认

## 测试命令参考

### Python (pytest)
```bash
# 运行所有测试
pytest

# 运行指定目录
pytest tests/

# 运行指定文件
pytest tests/test_api.py

# 显示覆盖率
pytest --cov=backend tests/
```

### JavaScript (npm)
```bash
# 运行所有测试
npm test

# 运行指定文件
npm test -- login.test.js

# 显示覆盖率
npm test -- --coverage
```

## 使用方式

```
使用 spec: run-tests

测试范围：全量 / 指定模块
```
