# 调试问题

## 目标

定位和修复代码问题，并提供预防措施

## 输入

- 问题描述（错误信息、复现步骤）
- 相关代码或文件路径
- 环境信息

## 输出

- 根因分析
- 修复方案和代码
- 预防措施（测试、监控、文档）

## 执行步骤

### 1. 理解问题
- 阅读错误信息
- 了解复现步骤
- 确认环境信息

### 2. 复现问题
- 按照步骤复现
- 确认问题现象
- 收集相关日志

### 3. 定位根因
- 分析错误堆栈
- 检查相关代码
- 追踪数据流
- 使用调试工具

### 4. 分析原因
- 识别直接原因
- 分析深层原因
- 评估影响范围

### 5. 设计修复方案
- 提出修复方案
- 评估方案风险
- 选择最佳方案

### 6. 实施修复
- 修改代码
- 添加必要的检查
- 改进错误处理

### 7. 验证修复
- 重新测试问题场景
- 运行相关测试
- 确认问题解决

### 8. 预防措施
- 使用 #test-engineer.md 添加测试
- 改进日志和监控
- 更新文档

## 调试技巧

### 日志分析
- 查看错误日志
- 追踪请求链路
- 分析时间戳

### 代码审查
- 检查最近改动
- 查看相关代码
- 分析依赖关系

### 数据验证
- 检查输入数据
- 验证中间状态
- 确认输出结果

## 使用方式

```
使用 spec: debug-issue

问题描述：
[描述问题现象和错误信息]

复现步骤：
1. ...
2. ...

相关文件：
[文件路径]
```
