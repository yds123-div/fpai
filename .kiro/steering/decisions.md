# 架构决策记录（ADRs）

重要技术决策及原因，便于后续上下文与评审。

## Decision 001：检索服务采用 LLM + Milvus + Embedding + Reranker（S1）

**标题：** 用户检索内容的回答链路采用 Milvus 向量库 + Embedding + Reranker + LLM

**原因：**
- 语义检索与生成链路职责清晰
- Milvus 专为向量场景设计，扩展性与检索性能更好
- 与现有技术架构图一致，便于落地与运维统一
- RAG 回答质量与引用可控性更优

**日期：** 2025-03

---

## Decision 002：合规审查采用统一大模型审查（S2）

**标题：** 输入与输出均经同一套 LLM 合规流程审查

**原因：**
- 满足金融领域对输出合规的强约束
- 敏感主题、承诺收益、夸大宣传等由大模型统一判断
- 可配置/可灰度/可回滚
- 审查依据与模型版本可写入审计

**日期：** 2025-03

---

## Decision 003：证据与审计冷热分层、保留 6 个月、支持审计导出（S3）

**标题：** 审计与证据数据采用冷热分层存储，保留周期 6 个月

**原因：**
- 近期热数据可查，超期归档至冷存储，兼顾查询性能与成本
- 满足内外部审计与合规检查
- 保留期满前可审批延长或销毁

**日期：** 2025-03

---

## Decision 004：关系型数据库选用 MySQL

**原因：**
- 与技术架构图数据存储层一致
- 行内已有 MySQL 运维与备份体系
- 内网私有化部署友好
- 会话/消息/审计索引等模型适合关系型

**日期：** 2025-03

---

## Decision 005：对象存储选用 MinIO

**原因：**
- 技术架构图明确 MinIO
- 内网可自建，无公网依赖
- S3 兼容便于后续迁移或混合云策略

**日期：** 2025-03

---

## Decision 006：前端技术栈 Vue3 + Vite + Ant Design Vue + SSE/WebSocket

**原因：**
- 与技术架构图前端交互层一致
- SSE 满足对话/报告流式推送，实现简单
- WebSocket 保留用于双向实时场景

**日期：** 2025-03

---

## Decision 007：多智能体框架采用 Agent Scope

**原因：**
- 技术架构图指定
- 与架构中 Orchestrator + Agent Runtime 的职责对应
- 支持智能体注册、路由与任务编排
- 便于智能体可插拔与扩展

**日期：** 2025-03

---

## Decision 008：API 统一响应结构与流式事件类型

**原因：**
- 前端统一处理成功/业务错误/合规拒答
- 审计与证据通过 answerId、trace 关联
- 流式事件与 architecture 中契约一致

**日期：** 2025-03

---

## Decision 009：多智能体编排由 AgentScope 推理驱动

**标题：** 采用 AgentScope 作为多智能体框架；意图识别结果作为上下文注入，由 AgentScope 在运行时推理决定调用哪些能力

**原因：**
- AgentScope 理念为"释放模型的推理与工具调用潜能"
- ReAct 通过 thought→action→observation 自选工具
- MsgHub 提供多智能体消息编排
- 意图与能力映射表作为可用工具清单，用于注册到 Toolkit

**日期：** 2025-03

---

## Decision 010：一期后端全 Python，不引入 Go

**原因：**
- 一期目标为 200 并发、P95≤5s，Python 异步 I/O 可满足
- 瓶颈主要在 LLM/检索/外部数据源，不在网关
- 单语言降低实现、调试与运维成本
- AgentScope 与编排、检索、合规等同进程，无跨语言 RPC

**日期：** 2025-03

---

## Decision 011：本系统维护用户表，支持账号+密码登录

**原因：**
- 业务需求变更：需要本系统自管用户与登录
- 用户表记录账号、密码哈希、姓名、工号、邮箱等
- 登录流程：POST /api/v1/auth/login 校验后颁发 Token
- 可选后续与企业 SSO/统一身份打通

**日期：** 2025-03

## 错误码约定

- **0**：成功
- **4xx 段**：客户端错误（参数、鉴权、限流等）
- **5xx 段**：服务端错误
- 当前子码见 `backend/pkg/codes.py`
