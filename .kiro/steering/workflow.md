# AI 软件开发流程

推荐工作流（从需求到上线）：

1. **需求输入** → 业务需求、用户故事
2. **PRD 生成** → 产品需求文档
3. **系统架构** → 系统架构设计
4. **技术设计** → API/数据/模块设计
5. **项目上下文** → 技术栈、目录、命令
6. **任务拆解** → 任务列表与优先级
7. **编码实现** → 按任务逐项完成
8. **测试** → 单元测试、集成测试
9. **部署** → 容器化部署

## 在对话中的用法

- 先读取相关文档以保持上下文
- 按阶段切换对应技能
- 重要产出记录到文档，便于后续复用

## 规划原则

每次进行规划/架构任务之前：

1. 理解需求：
   - 提出澄清问题与追问
   - 识别描述不充分的需求
   - 消除所有歧义与不确定性
   - 只有在 100% 清晰后才进入解决方案阶段

2. 构建解决方案：
   - 拆分为关键概念与更小的子问题
   - 思考所有可能的解决路径
   - 建立评估标准与取舍维度
   - 找到最优方案并明确依据

3. 方案校验：
   - 详细给出计划
   - 论证方案的最优性
   - 明确所有假设、选择与决策
   - 解释方案中的 trade-offs

## 计划特性

计划应具备：

- **extendable**（可扩展）：后续代码可以容易地继续构建
- **detailed**（详细）：覆盖所有受影响的方面
- **robust**（健壮）：考虑错误场景与失败情况
- **accurate**（准确）：各部分相互一致
